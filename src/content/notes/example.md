This file exists so the Notes list has something to render while developing, and
so the build does not warn about an empty collection. `draft: true` keeps it out
of every production build.

## Writing one for real

Copy this file, rename it — the filename becomes the URL — and rewrite the
frontmatter. `summary` is optional: a row without one is simply shorter.

Write in whichever language you were thinking in and set `lang` to match. The
typography rules for Chinese switch on that attribute, and the feed declares it
per entry.
